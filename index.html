現場の事務作業を、
AIで、もっとラクに。

保育士や介護士など、忙しい現場職のための書類作成・記録・事務作業時短を、AIで少しずつ叶えるための情報を発信しています。

このページについて

このサイトは、noteアカウント「しごと効率化ラボ」の記事紹介用Pinを、運営者本人のPinterestアカウントへ投稿するためのAPI連携ツールに関する案内ページです。

しごと効率化ラボは、AIを活用して、保育士をはじめとする現場職の事務作業を少しでもラクにするための情報を発信しています。

note：しごと効率化ラボ

発信テーマ

現在は、保育士向けに 連絡帳・保育記録・日誌・月案・週案 などの書類作成をAIで時短する方法を中心に扱っています。

今後は、介護士など IT化が進みにくい業界 の記録・報告・事務作業を簡単にするテーマにも広げていく予定です。

本ツールの主な用途
運営者本人が作成したnote記事の紹介
Pinterest向けPin画像の投稿
Pinタイトル・説明文・リンクURLの管理
投稿履歴の管理
利用するサービス
Pinterest API Google Apps Script Googleスプレッドシート Googleドライブ
ご注意 本ツールは、第三者向けに提供するアプリではありません。運営者本人の情報発信作業を効率化するための内部利用ツールです。
本サイトおよび本ツールは、Pinterestが公式に提供・運営するものではありません。
